# Tradium Insights

Design a premium fintech trading dashboard called "Tradium.". create in light mode. The product should feel like it was designed by a small, obsessive, design-led startup team — think Stripe Dashboard, Mercury, Linear, Vercel, or Ramp. Calm, precise, quietly confident.

Generate the following screens, using your own judgment for the best composition, spacing, depth, and visual hierarchy — prioritize a polished, editorial, high-end feel over rigid symmetry: 1. Dashboard (main landing after login): personalized greeting, key portfolio metrics (portfolio value, today's P&L, total investment, available margin), a portfolio performance chart over time with selectable time ranges, a compact watchlist of tracked stocks, a preview of top holdings, a preview of recent orders, and a reserved area for future "AI Insights" (can be a simple coming-soon element). 2. Holdings page: full table of owned stocks (quantity, avg buy price, current price, value, P&L), with sort/filter options and an aggregate summary at the top. 3. Positions page: open/intraday positions with entry price, current price, and P&L, clearly distinguishing profitable vs losing positions. 4. Orders page: full order history with instrument, type, quantity, price, status, and timestamp, with tabs or filters for order status. 5. Watchlist page: expanded list of tracked instruments with more detail per row (price, day change, volume) and the ability to add/remove instruments. 6. Funds page: available balance, used margin, total balance, add/ withdraw fund actions, and a simple transaction history. 7. Instrument detail / trade page: large stock chart (candlestick or line) with selectable time ranges, price header with day change, key stats (open/high/low/volume/52-week range), and a buy/sell order panel (order type, quantity, price, estimated total) — this should feel like the most "active" screen in the app, where a user actually places a trade.

dont use a typical left sidebar with icon navigation (avoid this — it looks like a generic admin template).

The overall goal is a portfolio-quality design that looks like a real funded fintech product.
